# 镜库 · 政企视频拉片与灵感库工作台

把别人拍得好的政企视频（B 端产品演示、企业宣传片等）收进自己电脑，拆成「文案 + 画面 + 手法 + 可复用亮点」，打上标签后随时筛选。资料只存在本机 `data/`（本地素材库目录），原片不会上传到网上。

## 它能做什么

1. **片库**：导入本地视频，或粘贴 B 站/官网等公开链接下载。
2. **拉片台**：左边是整段文案（带时间，点击跳转）；当前段显示主题、要点 1/2/3、制作手法、对应画面帧；下方是可改的亮点卡。
3. **灵感库**：把亮点打上标签后筛选复用，例如「痛点开场」「数据金句」，点进去回到原片对应时间。

B 端演示和企业宣传片用同一套工作台，分析口吻不同（在导入时选片种即可）。

## 怎么启动

本机需要：Python 3.9+、Node.js、已经安装好的 `ffmpeg`（切画面用，你这台电脑已经有了）。

在项目根目录执行：

```bash
chmod +x start.sh
./start.sh
```

第一次会安装依赖，并下载 Whisper 语音模型（大约几百 MB）。然后浏览器打开：

**http://127.0.0.1:5173**

也可以分开启动：

```bash
# 终端 1：后端
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8765 --reload

# 终端 2：前端
cd frontend
npm install
npm run dev
```

## 日常怎么用

1. 打开 **设置**，点「阿里云百炼（通义，推荐）」，把 API Key 填进「写亮点」一栏。转写默认用本地 Whisper，可以先不填云端转写。
2. 打开 **片库**，右上角先选片种（B 端产品演示 / 企业宣传片 / 其他），再拖入视频或「从链接导入」。
3. 点进 **拉片台**，点「开始 AI 拉片」。等进度走完：逐字稿、分段、画面帧、亮点草稿都会出来。
4. 对照视频改不准的地方，点「保存本段」。勾选「收入灵感库」。
5. 做新片子时去 **灵感库**，按标签 / 片种 / 受众筛选。

没有填 Key 时，仍然会转写并按时间切段，亮点卡留空给你手写。

## 模型怎么配

设置存在 `data/settings.json`（本机配置，不会进 git）。三个任务可以分开：

| 任务 | 默认 | 说明 |
| --- | --- | --- |
| 转写 `asr_provider`（语音变文字） | 本地 Whisper，模型 `small` | 可改 `medium` 提高中文专有名词准确度；或改成 OpenAI 兼容转写 |
| 写亮点 `text_model`（文本模型） | 通义 `qwen-plus` | 国内推荐阿里云百炼；也可以换成 DeepSeek、豆包接入点 |
| 看画面 `vision_model`（视觉模型） | 通义 `qwen-vl-plus` | 给参考图写说明、结合画面写制作手法 |

发给网上模型的只有「文案 + 少量截图」，4K 原片留在本机。

## 文件放在哪

```
data/
  jingku.db          本地数据库（视频、文案、段落、亮点、标签）
  settings.json      模型 Key 与接口地址
  videos/<视频id>/
    source.mp4       原片
    thumb.jpg        封面
    audio.wav        转写用音轨
    frames/          关键帧截图
```

删除片库里的条目时，对应文件夹会一起删掉。

## 三个页面说明

### 片库

- 拖放或选择本地文件 → 复制到 `data/videos/`（本地视频目录），抽出封面和时长。
- 从链接导入 → 后台用 `yt-dlp`（公开链接下载器）拉取，状态显示「下载中」。
- 卡片上可看到片种、状态（待拉片 / 分析中 / 已拉片）、时长、亮点数量。

### 拉片台

- 播放器与时间条：点击逐字稿某一句，视频跳到该时间。
- 右侧当前段：主题、要点、制作手法，均可改。
- 画面帧：本段 3 张关键帧，点图也会跳转。标了「参考图」的会显示在亮点卡下面。
- 亮点卡：文案建议、画面建议、受众、标签、是否入库。

### 灵感库

- 筛选条件：关键词、片种、标签、受众。
- 卡片展示标题、时间码、文案建议、画面建议、参考图、标签。
- 「回到原片这段」打开拉片台并跳到对应时间。

## 主要接口（给以后改功能时对照）

基址：`http://127.0.0.1:8765`

- `GET /api/health`：探活。返回 `{ ok, name }`。
- `GET /api/videos`：片库列表。
- `POST /api/videos/upload`：表单字段 `file`（视频文件）、`title`（标题）、`genre`（片种：`b2b_demo` / `corp_promo` / `other`）。
- `POST /api/videos/from-url`：JSON `{ url, title, genre }`，返回 `{ video, job }`。
- `GET /api/videos/{id}`：拉片详情，含 `cues`（逐字稿）、`segments`（段落）、`latest_job`（最近任务）。
- `POST /api/videos/{id}/analyze`：开始 AI 拉片，返回任务 `job`。
- `GET /api/videos/{id}/jobs/{job_id}`：轮询进度（`progress` 0–100，`message` 当前步骤）。
- `PUT /api/videos/{id}/segments/{segment_id}`：改主题 / 要点 / 手法。
- `PUT /api/videos/{id}/highlights/{highlight_id}`：改亮点卡，`tags` 为字符串数组。
- `GET /api/highlights?tag=&genre=&audience=&q=`：灵感库列表。
- `GET /api/tags`：全部标签。
- `GET/PUT /api/settings`：模型配置。PUT 时 Key 留空表示不修改已保存的值。
- `GET /media/{相对路径}`：播放原片、显示截图。

## 已知边界（第一期）

- 网盘链接请先自己下载，再导入本地文件。
- 有的网页会防下载，失败时改用本地导入。
- AI 草稿会有错，尤其是专有名词和制作手法，**改完再当真资产**。
- 第一次本地转写要下载模型，时间会比较长。
